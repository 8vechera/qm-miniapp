# Клиентский мини-апп · видео-продакшен

Первый из трёх мини-аппов студии. Показывает **портфолио**, **команду**, **о студии**
и кнопку **«Обсудить проект»** (ведёт в личку менеджера в Telegram).

## Что где лежит

```
client-app/
├─ index.html        ← страница (structure). Трогать не нужно.
├─ css/styles.css    ← оформление. Цвета бренда — вверху файла в блоке :root.
└─ js/
   ├─ data.js        ← ★ ЕДИНСТВЕННЫЙ ФАЙЛ ДЛЯ РЕДАКТИРОВАНИЯ: проекты, команда, тексты.
   └─ app.js         ← логика. Трогать не нужно.
```

## Как поменять содержимое (без программирования)

Открой `js/data.js` — там всё подписано по-русски:
- **Название и подзаголовок** студии.
- **managerUsername** — ник менеджера в Telegram без `@` (на него ведёт кнопка заказа).
- **portfolio** — список видео. Для каждого укажи `type` (`youtube`/`vimeo`) и `id`.
  - YouTube-ссылка `youtube.com/watch?v=**abc123**` → `id: "abc123"`.
  - Vimeo-ссылка `vimeo.com/**123456789**` → `id: "123456789"`.
- **team** — команда: имя, роль, фото (или пусто → покажутся инициалы).
- **about** — текст «О студии».

## Как посмотреть локально

В папке `client-app` запусти простой веб-сервер (нужен установленный Python):

```powershell
python -m http.server 8080
```

Затем открой в браузере: <http://localhost:8080>
Нижняя кнопка Telegram в браузере заменяется обычной кнопкой — это нормально.

## Как поменять фирменные цвета

`css/styles.css`, самый верх, блок `:root`:
```css
--accent: #E5573F;   /* главный цвет: кнопки, активная вкладка */
--bg:     #0d0d0f;   /* фон */
```
Замени на цвета студии.

## Что дальше (следующие шаги)

1. Заполнить `data.js` реальными видео и командой.
2. Поставить фирменные цвета и лого.
3. Выложить на бесплатный хостинг (сделаем ссылку `https://...`).
4. Создать бота в @BotFather и привязать Mini App к этой ссылке.
