# Бэкап рабочей анимации объектива — 2026-07-20

Рабочая версия hero-анимации (3D-разбор объектива Canon) на момент **до заключительной поправки**.

## Что зафиксировано в этой версии
- Задняя рифлёная заглушка — один цельный кусок, отъезжает назад.
- Внутренний цилиндр (`Cylinder003`) — скрыт (убран из сцены).
- Направление разбора: перёд → вперёд, зад → назад (схема rank-ADD, `EXPAND = 1.2`).
- Передние ребристые кольца (`top ring` + `bottom ring`) — склеены, едут вместе.
- Панель переключателей (STABILIZER / AF-MF) — отходит вбок единым блоком.
- Надписи/шкалы/логотипы — «прилипают» к своим деталям.

## Файлы
- `lens.html` — сама сцена (Three.js) со всей логикой анимации.
- `assets/camera_lens_parts.glb` — обработанная модель, которую грузит `lens.html`.
- `assets/camera_lens.glb` — исходная модель Canon (до нарезки на детали).
- `process_final.py` — Blender-скрипт, которым `camera_lens_parts.glb` собран из исходника.
- `diag_render.py` — Blender-скрипт для диагностических рендеров сцены (headless).

## Как откатиться
Скопировать обратно в `client-app/`:
```
cp _backup/2026-07-20_working-animation/lens.html                     lens.html
cp _backup/2026-07-20_working-animation/assets/camera_lens_parts.glb  assets/camera_lens_parts.glb
```
(при необходимости — и `camera_lens.glb`).
